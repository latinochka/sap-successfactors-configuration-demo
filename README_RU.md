# Демонстрационный пакет конфигурации SAP SuccessFactors

В репозитории собран небольшой технический пример на основе моего опыта с SAP SuccessFactors Recruiting Management и моделями данных сотрудников.

Файлы пересобраны специально для портфолио. Названия организаций, внутренние идентификаторы, настройки конкретного клиента, персональные данные и уникальные бизнес-правила удалены или заменены.

## Что входит в пакет

- `xml/candidate-profile-template-demo.xml` - нейтральный шаблон профиля кандидата со стандартными и кастомными полями, пиклистами, полномочиями и настройками отображения.
- `xml/succession-data-model-demo.xml` - сокращённая модель данных сотрудника с подписями на русском и английском, кастомными полями, повторяющимися блоками и полномочиями.
- `docs/field-catalog.csv` - удобный каталог полей из двух примеров.
- `docs/anonymization-notes.md` - список изменений перед публикацией.
- `scripts/validate_xml.py` - небольшой скрипт для проверки корректности XML и корневых элементов.

## Какие навыки показывает пакет

- анализ структуры HR-данных;
- настройка стандартных и кастомных полей;
- локализация RU/EN;
- работа со справочниками;
- ролевые полномочия на поля;
- повторяющиеся блоки для опыта, образования и сертификатов;
- подготовка технических артефактов для согласования и хранения в Git.

## Важно

Это демонстрационные файлы для портфолио. Они являются корректным XML, но не предназначены для загрузки в рабочий tenant без проверки версии, DTD, модели полномочий и бизнес-правил.

## Проверка

```bash
python scripts/validate_xml.py
```
